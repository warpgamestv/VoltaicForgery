# Pre-Crucible Progression

Default early progression is:

1. Craft a `voltaicforgery:pattern_table`.
2. Craft `voltaicforgery:blank_pattern` items.
3. Use the Pattern Table with blank patterns and wood or stone materials to make early tool parts.
4. Assemble early modular tools from those parts.
5. Craft `voltaicforgery:unfired_crucible_brick` from clay, sand, and gravel.
6. Fire unfired crucible bricks into `voltaicforgery:crucible_brick` by smelting, blasting, or campfire cooking.
7. Craft `voltaicforgery:crucible_bricks`, then use those blocks for the first crucible and casting setup.

The Pattern Table material allow list stays data-driven through `voltaicforgery:pattern_tool_part` recipes. The stats and tint for the resulting tool parts come from the `voltaicforgery:tool_materials` datapack registry.
